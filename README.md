# AidKit
Offline-first first-aid guide and medicine tracker with missed-dose nominee alerts.
## Install & Run
Run `npm install` followed by `npm run dev` (or `npm run build && npm run preview`).
## How Offline Works
Service worker precaches all bundles, assets, and guides; Dexie stores data in client-side IndexedDB.
## 2-Minute Demo Steps
1. In Profiles tab, add a profile with name and nominee contact details.
2. Open ⚙️ Settings, enable "Demo Mode (1 min grace)", and click "Add Test Dose Due in 1 Minute".
3. Wait 60s: observe full-screen alarm, audio alert, and prefilled nominee emergency SMS prompt.
